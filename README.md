# 📒 Address Book

A simple **C-based Address Book application** for managing contact information using structures and file handling.

## ✨ Features

* ➕ Add contacts
* 🔍 Search contacts
* ✏️ Edit contacts
* 🗑️ Delete contacts
* 📋 Display all contacts
* 💾 Save contacts to a file

## 🛠️ Technologies

* C
* Structures
* File Handling
* String Handling

## ▶️ Compile & Run

```bash
gcc *.c -o addressbook
./addressbook
```

## 📂 Data Storage

Contacts are stored in a CSV file:

```text
contacts.csv
```
